# Naming clearance checklist

“BitLock” is a working name only. Complete these checks before public release:

- [ ] Search relevant trademark registries in target markets and get legal review.
- [ ] Confirm the Google Play listing name is available.
- [ ] Confirm suitable domain names and social handles are available.
- [ ] Check for confusingly similar security products and package names.
- [ ] Record the owner, date, evidence, and final go/no-go decision here.
