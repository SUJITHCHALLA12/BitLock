# MVP release map

| Release | Scope | Status |
|---|---|---|
| v0.1 | Phase 0 + Phase 1 + Phase 2: local vault, PDF/image/text viewer, FLAG_SECURE, watermark, local audit; no temporary or one-time shares | Not released; phase gates pending |
| v0.2 | Phase 3 + Phase 4 + basic Phase 5 viewer: cloud, protected links, expiry, max uses, revocation, device binding | Planned |
| v0.3 | Phase 5 complete + Phase 6: versioning, change requests, comments, archive listing | Planned |
| v1.0 | Phase 7: organizations, RBAC, admin console, API, web viewer, audit export, managed key seam | Planned |

A release is not complete until every included phase passes its acceptance gate.
